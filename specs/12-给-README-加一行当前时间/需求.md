# 需求：给 README 加一行当前时间

对应计划：无

## 要什么
在 `README.md` 的末尾追加一行，内容是当前时间，UTC，ISO 8601 格式，例如 `2026-09-26T07:30:00Z`。

- 只追加，不改 README 已有内容（包括之前巡检留下的 `<!-- 真机验收 … -->` 注释行）。
- 时间取动手写这行时的实际 UTC 时间，精确到秒，以 `Z` 结尾。
- 原话只说"加一行当前时间"，没要求注释包裹或前缀文字；按原话写成一行可见的时间即可。

## 背景
仓里没有 `specs/` 历史需求，也没有 `plan.md`。之前改 README 末尾的都是巡检提交（#2、#4、#6、#8、#10），做法一致：在末尾追加一行、与上一行隔一个空行。本次沿用这个格式。

## 怎么算做完
1. `README.md` 最后一行是一个 UTC 时间（形如 `YYYY-MM-DDTHH:MM:SSZ`），其余内容不变。
2. 改动通过 PR 合进 `main`。
3. 需求 #12 关闭。
