# 方案：巡检第 5 轮（#20）

## 现状

- 仓根已有 `巡检记录.md`（第 3 轮 #17 建的），内容三行，最后一行 `- 第 3 轮 2026-09-27T14:02:27Z`，末尾有换行符。所以走「末尾追加」这条，不新建。
- 记录里没有第 4 轮。第 4 轮不归本单管，本单不补、不动已有行，照单只追加第 5 轮。
- 若合并前主线上又有别的巡检单往这份文件追加了行（比如第 4 轮），合并时保留那些行，本单这一行仍放在最末。
- `.gitattributes` 规定 `* text=auto eol=lf`：LF 换行、UTF-8 无 BOM，新行末尾带一个换行符。
- `node --test` 跑的是 `log.test.mjs`，本单不碰代码，不会影响。

在 `巡检记录.md` 末尾追加一行（后跟换行符）：

```
- 第 5 轮 2026-09-27T14:19:21Z
```

已有内容一个字不动。

## 改哪些文件

- `巡检记录.md`（追加一行）
- `specs/20-巡检第5轮往巡检记录追加一行/` 下本单文档（需求.md、方案.md，以及之后的结果.md）

别的文件一个不动。

1. `tail -n 1 巡检记录.md` 输出 `- 第 5 轮 2026-09-27T14:19:21Z`，一字不差（数字与汉字之间是半角空格）。
2. `git diff 起点..HEAD -- 巡检记录.md` 只有一行 `+`，没有 `-`。
3. `git diff --name-only <分支起点>..HEAD` 只列出 `巡检记录.md` 和本单 specs 目录下的文件。
4. `node --test` 通过。
